# Diagrama Entidad–Relación (DER)

El DER conceptual del proyecto se realizó en **ERDPlus** utilizando notación **P. Chen**, de acuerdo con la consigna de la cátedra.

Para esta reconstrucción se conserva como referencia el DER elaborado por el equipo en el repositorio original:

https://github.com/CamilaHornoss/proyecto-bd1-equipo_30/blob/main/docs/etapa-02/der/der-etapa02.png

El modelo relacional implementado en esta versión mantiene las entidades principales del caso: Cliente, Producto, Categoría, Proveedor, Compra, Venta, Detalle de Compra, Detalle de Venta, Método de Pago y Pago.

> Antes de utilizar este repositorio como entrega definitiva conviene exportar nuevamente desde ERDPlus el DER actualizado y guardar el PNG en esta misma carpeta, para que el diagrama y el DDL representen exactamente la misma versión del modelo.
